Instalación desde el navegador

Microsoft Edge

  1. Abre esta página en Edge.
  2. Pulsa el icono de instalación en la barra de direcciones, o el menú ⋯ → Aplicaciones → Instalar este sitio como una aplicación.
  3. Confirma Instalar. En las opciones posteriores, elige Crear acceso directo en el escritorio y, si quieres, anclar a Inicio o a la barra de tareas.

Google Chrome

  1. Abre esta página en Chrome.
  2. Pulsa el icono de instalación en la barra de direcciones, o ⋮ → Enviar, guardar y compartir → Instalar página como aplicación.
  3. Confirma Instalar. Busca SuperTools en Inicio y crea el acceso directo desde las opciones de la aplicación.

El nombre de las opciones puede variar según la versión. Si ya está instalada, ábrela desde Inicio. Si tu empresa restringe instalaciones, puedes seguir usando la versión web.

Requiere conexión para cargar la app y los datos compartidos. Los borradores y fotos locales pertenecen al perfil del navegador: no se transfieren automáticamente desde el teléfono ni entre navegadores.

Para quitarla, usa Aplicaciones instaladas de Windows. Conserva los datos del sitio si quieres seguir usándolos en el navegador.
